# Coriolis Roadmap

Area| Planned improvements| Expected  
---|---|---  
**Migration Experience**|  Improved endpoint validation, smarter defaults, guided migration setup, and reusable migration templates| **Q4 2026 - Q1 2027**  
**Data checksum**|  Faster data transfers and post-transfer data integrity verification| **Q2 2026**  
**Platform Support**|  Additional support for Nutanix, CloudStack, and StackIT| **Q3 2026**
**Multi-VM & Cluster Migration**| Coordinated shutdown of multiple VMs and support for migrating clustered workloads, including shared disks where supported| **Q3-Q4 2026**  
**Disaster Recovery**|  DR failback capabilities, initially focused on the platforms most requested by customers| **Q1-Q2 2027**  
**Public Cloud Support**|  Expanded migration support to GCP| **TBD**
